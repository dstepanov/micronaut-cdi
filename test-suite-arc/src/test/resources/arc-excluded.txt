# Tests that passed the filter in build.gradle and still cannot run here, one line each with the reason.
# A test is on this list only where what it asserts is ArC's and not the specification's; a test that fails
# because this implementation is wrong is a bug to fix, not a line here.

# ArC publishes the interceptor bindings of an invocation in the invocation context's context data, under a key
# of its own. The specification's InvocationContext has no such entry, and Jakarta Interceptors does not put one
# there, so every interceptor of ArC's suite that reads the key throws before it proceeds. Seventeen tests reach
# one of those interceptors.
io.quarkus.arc.test.interceptors.SimpleInterceptorTest
io.quarkus.arc.test.interceptors.arcInvContext.ArcInvocationContextTest
io.quarkus.arc.test.interceptors.aroundconstruct.AroundConstructAppliedViaConstructorTest
io.quarkus.arc.test.interceptors.aroundconstruct.AroundConstructReturningObjectTest
io.quarkus.arc.test.interceptors.aroundconstruct.AroundConstructTest
io.quarkus.arc.test.interceptors.bindings.InvocationContextBindingsTest
io.quarkus.arc.test.interceptors.bindings.transitive.TransitiveInterceptorBindingTest
io.quarkus.arc.test.interceptors.bridge.BridgeMethodInterceptionTest
io.quarkus.arc.test.interceptors.constructor.SubclassConstructorGuardTest
io.quarkus.arc.test.interceptors.finalmethod.FinalNonInterceptedMethodTest
io.quarkus.arc.test.interceptors.intercepted.InterceptedBeanInjectionTest
io.quarkus.arc.test.interceptors.limits.SubclassLimitsTest
io.quarkus.arc.test.interceptors.methodargs.MethodArgsInterceptionTest
io.quarkus.arc.test.interceptors.mixed.BusinessLifecycleInterceptorTest
io.quarkus.arc.test.interceptors.nonpublicparams.NonPublicParametersTest
io.quarkus.arc.test.interceptors.privatemethod.PrivateInterceptorMethodTest

# @WithCaching is ArC's: it has a programmatic lookup remember what it resolved, and the test clears the cache
# through a cast to ArC's own Instance. The specification has Instance.get() resolve afresh every time.
io.quarkus.arc.test.instance.cacheget.InstanceWithCachingTest

# AsyncObserverExceptionHandler is ArC's own SPI for what becomes of an exception an asynchronous observer threw.
io.quarkus.arc.test.observers.async.CustomAsyncObserverExceptionHandlerTest

# ArC's mocking support, which replaces a bean's instance for the duration of a test, with Mockito.
io.quarkus.arc.test.mocking.SpyOnInterceptedBeanTest

# A bean in a normal scope may not declare a public instance field (section 2.7): it is reached only through its
# proxy, and a public field would be read past it. ArC does not enforce it, and these deployments declare one -
# ObservingBean a public field of its own, and the two producer tests a public producer field.
io.quarkus.arc.test.observers.inheritance.ObserverInheritanceTest

# Section 3.3.7 makes a disposer method that no producer of its class is bound to a definition error. ArC ignores
# such a disposer instead, and these deployments declare disposers with qualifiers no producer of theirs carries,
# on purpose - the comment in the source says "this one should be ignored".
io.quarkus.arc.test.producer.disposer.DisposerWithQualifiersTest
io.quarkus.arc.test.producer.disposer.DisposerWithAndWithoutQualifiersTest

# Both of the above, and a third thing: this deployment qualifies its producers and disposers with a repeatable
# qualifier written twice. The disposer matching of cdi-processor reads one occurrence of a repeated qualifier
# where there are two, and compares the qualifiers of a disposed parameter with a producer's for equality where
# section 3.3.7 resolves them the way an injection point is resolved, so every disposer here matches every
# producer. That is this implementation's bug rather than ArC's, recorded here until it is fixed.
io.quarkus.arc.test.qualifiers.RepeatingQualifierProducerTest

# A class level interceptor binding is carried onto the producer methods of the class, and the bean a producer
# produces is then proxied as though it were intercepted - which a long cannot be. A producer method is not a
# business method of the bean that declares it (Jakarta Interceptors section 3.1), so the binding should not
# reach it. This implementation's bug rather than ArC's, recorded here until it is fixed.
io.quarkus.arc.test.transientreference.TransientReferenceDestroyedTest

# The deployment of a test that expects to be rejected: this is the abstract base class its shouldFail subclasses
# share, and the beans it declares are deliberately unproxyable. It belongs with the negative tests.
io.quarkus.arc.test.validation.AbstractNormalScopedFinalTest
